# baka launcher

这是一个依赖于 baka.exe 的启动器，用于快速启动以及让 baka 们跳舞。

[baka.exe](https://github.com/Arrokoth486958/cirno-is-baka/tree/master)

## 依赖

- Windows 10 / 11
- PowerShell 5.1 及以上

## 准备

1. 下载本仓库的 `baka_launcher.zip`，解压到独立文件夹。
2. 自行获取 `baka.exe`，将其放在上一条的独立文件夹中。
3. 运行 `baka.bat`，在新建的 `music` 文件夹放入你想要的音频文件，建议使用 `.mp3`。

## 目录结构

独立文件夹
├── baka.exe
├── baka_launcher.ps1
├── baka.bat
└── music
└── 音频文件.mp3
